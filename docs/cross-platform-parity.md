# Readio cross-platform parity matrix

Status: audited implementation baseline  
Baseline: `main@00773b0` plus the uncommitted Rust SDK, Web, Cloud, TUI, and Apple integration work verified on 2026-08-10  
Product target: Web, iPhone, iPad, and native macOS must provide at least the same user outcomes as the TUI. The browser extension is a companion surface with role-specific parity for capture, local persistence, deduplication, optional sync, and optional TTS. Platform-native interaction may differ.

## How to read this document

- **C — Complete:** the observable TUI outcome exists on the platform and has proportionate automated evidence.
- **P — Partial:** a related surface exists, but one or more TUI invariants or recovery paths are absent.
- **M — Missing:** no product path currently provides the outcome.
- **N/A:** the concern does not belong on that layer.
- A status is not complete because a screen or method exists. It becomes complete only when the acceptance contract in this document passes.
- `App` means the current iPhone/iPad SwiftUI target. `Desktop` means a native macOS product, not Catalyst, Electron, or Tauri.

## Non-negotiable invariants

1. Reading position has one durable authority: a canonical Unicode-scalar offset plus affinity. A bounded `TextLocator` audits cross-revision recovery in the fixed order exact revision → stable block → unique quote → explicit scalar fallback; chapter, block, sentence, percentage, DOM/native range, and visual scroll position are projections.
2. Playback has one authoritative media clock. UI timers may sample it; they may not invent progress.
3. Manual, Auto, and Read-aloud are persistent peer modes. TTS failure never silently changes the selected mode.
4. User-visible progress, result counts, queue state, and fallback behavior are real and inspectable.
5. Portable state transitions, clocks, document semantics, search, position mapping, pace, and recovery policy belong in Rust Core. Rendering, audio devices, persistence transports, and OS integration remain platform effects.
6. Cloudflare Worker is the real network backend for anonymous bounded URL acquisition, account, CRDT sync, content, and cloud TTS orchestration. Python/FastAPI is an optional TTS provider plus a temporary compatibility surface; no client requires it for ordinary reading or new URL import.
7. Platform parity means equivalent outcomes, not terminal-command imitation.
8. The browser extension runs the same Rust/WASM SDK as Web. Extension-only code owns active-tab capture, selection, permissions, popup UI, and Chrome storage; it may not grow a second parser, identity algorithm, sync reducer, or playback state machine.

## Delivery order and gates

The order follows dependency direction. A platform screen cannot make a missing shared contract correct.

1. **Contract foundation:** exact position, document revision, bookmarks, full-text search results, reading mode, effort, sleep deadline, and Loro replica schemas.
2. **Rust Core:** pure reducers/services for position mapping, folded search, bookmarks, pace, playback/mode transitions, deadline logic, and versioned Document IR expansion.
3. **Cloudflare:** authenticated Loro change/heads/cursor endpoints in D1, private snapshots/content in R2, authoritative Auth/ACL/quota/TTS Job state, and anonymous bounded URL acquisition; retain FastAPI only as an optional Python TTS provider plus temporary compatibility routes.
4. **Web and extension:** load the real WASM module, replace duplicate player/parser policy, connect extension capture/local outbox/cloud handoff, then fill the tokenized Web list/detail/reader slots and global state surfaces.
5. **Apple:** package Rust FFI for Xcode, connect iPhone/iPad, add the native macOS target, then use AppKit selectively for macOS capabilities SwiftUI does not express well.
6. **Hardening:** offline behavior, accessibility/localization, diagnostics, cross-platform fixtures, E2E, performance budgets, and parity audit.

A phase is complete only when its matrix rows are green on every layer it changes and no previously green row regresses.
