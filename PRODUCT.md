# Product

## Register

product

## Users

People who read books and long-form documents in a terminal, often while staying in a keyboard-driven work context. They want a focused reader that handles real EPUB, PDF, Markdown, and text structure, can optionally use a local TTS model, and does not require a separate media-player workflow.

## Product Purpose

Readio makes sustained reading feel native inside a terminal by presenting the reading loop with the interaction grammar of a coding agent: streamed output, real tool calls, one command line, honest progress, and an interruptible turn. Success means the interface disappears into the reading task while every position, count, timing value, and file reference remains real.

## Brand Personality

Precise, calm, agent-native. The voice is terse and confident, with a small amount of theatre earned by real underlying data.

## Anti-references

- A conventional media player with music notes, transport chrome, timelines, or audio-app language.
- A dashboard made of cards, panels, decorative badges, or persistent controls that compete with the text.
- Repeated hints or state labels that explain the same fact in several places.
- Fake agent telemetry, fabricated file positions, or controls whose visual state does not match the actual clock.
- Silent fallbacks that change reading mode when TTS is slow or unavailable.

## Design Principles

1. Looking like a coding agent is a functional constraint, not decoration.
2. The book's words and every actionable number stay honest.
3. The status row teaches the single next action and reports each state once.
4. Manual, automatic, and spoken reading remain parallel modes with explicit transitions.
5. Audio, token reveal, highlighting, and interruption project from one authoritative clock.

## Accessibility & Inclusion

The complete reading loop is keyboard-operable. Meaning is never conveyed by color alone, active and interrupted states remain legible in both supported languages, and narrow terminals lose secondary hints before primary state. Animation is limited to state-bearing terminal frames and stops when the turn is interrupted.
